# DOCKLINE

크롬북과 마우스로 즐기는 학교 축제용 1v1·2v2·3v3 FPS. 40초 라운드에서 상대 팀을 전멸시키거나 연장전에 중앙 발판을 점령하세요. 먼저 세 라운드를 이기는 팀이 승리합니다.

## 바로 플레이

[브라우저에서 도크라인 플레이](https://juhyeonmoon10.github.io/dockline-summit/) · [축제용 LAN 서버 ZIP 다운로드](https://juhyeonmoon10.github.io/dockline-summit/dockline-lan.zip)

로비에서 경기장과 주무기, 보조 무기를 선택하세요. 세관 4번 창고에서는 검수실과 하역 데크 사이의 계근대를 놓고 싸웁니다. 서밋은 중앙 고가교가 있는 옥상입니다. 참가자 모두 방장이 고른 맵에서 경기합니다. **더미 사격장**에서는 선택한 맵의 더미 4개를 시간 제한 없이 쏠 수 있습니다.

| 조작 | 키 |
| --- | --- |
| 이동 · 시점 | WASD · 마우스 |
| 발사 · 조준 | 좌클릭 · 우클릭 |
| 점프 · 슬라이딩 | Space · 이동 중 C |
| 재장전 · 무기 교체 | R · 1(주무기) / 2(권총 또는 리볼버) / 3(칼) |
| 사격장에서 주무기 변경 | Q |
| 메뉴 · 마우스 감도 | Esc |

Esc 메뉴 또는 로비 오른쪽 위 설정에서 마우스 감도를 0.10–3.00배로 조절할 수 있습니다. 슬라이더나 숫자를 바꾸면 바로 적용되어 이 브라우저에 저장됩니다. 기본값은 1.00배입니다.

## 체력과 무기

일반 대전의 플레이어와 사격장 더미는 모두 150 HP입니다. 돌격소총·산탄총·저격소총·권총은 2026-11-06에 확인한 RIVALS 커뮤니티 기록을 기준으로 했고, 리볼버는 이 게임에 맞춰 조정했습니다. 탄창·예비탄, 재장전과 장착 시간, 거리 감쇠도 공통 데이터에서 계산합니다. [무기 수치](https://bloxguidesgg.com/games/rivals/wiki/weapons) · [장착 시간](https://bloxguidesgg.com/games/rivals/tier-list)

| 무기 | 몸통 / 머리 | 발사 간격 | 탄창 / 예비탄 | 150 HP 몸통 처치 |
| --- | --- | --- | --- | --- |
| 돌격소총 | 12 / 15 | 0.10초 | 20 / 100 | 13발 |
| 산탄총 | 8×10 / 12×10 | 0.70초 | 7 / 35 | 2발, 산탄 전부 명중 시 |
| 저격소총 | 50 / 150 | 1.50초 | 4 / 12 | 3발 |
| 권총 | 12 / 15 | 0.13초 | 13 / 91 | 13발 |
| 리볼버 | 38 / 72 | 0.43초 | 6 / 36 | 4발 |

저격 헤드샷은 150 피해입니다. 원작의 스터드 단위를 이 맵의 미터로 바꿔, 돌격소총은 14–56m, 권총은 14–35m, 산탄총은 2.8–14m에서 피해가 감소합니다. [감쇠 기록](https://gamesdatahub.com/wikis/rivals/weapons/) · [Roblox 길이 단위](https://create.roblox.com/docs/physics/units)

산탄총은 한 발씩 장전하며, 정확한 원작 삽입 시간 자료가 없어 한 발당 0.77초로 조정했습니다. 돌격소총과 권총의 조준 분산은 비조준 분산의 24%로 적용했습니다. 리볼버는 6발을 모두 쏜 뒤에도 한 번의 장전으로 다시 채울 수 있습니다. 권총·리볼버·지정사수소총은 클릭당 한 발을 발사합니다. 사격장의 예비탄은 무제한이고, 팀전의 탄창과 예비탄은 새 라운드마다 보충됩니다.

기존 주무기에 더해 스키퍼(기관단총), 트라이던트(3점사 소총), 글라스핀(지정사수소총), 캐프스턴(경기관총)을 선택할 수 있습니다. 트라이던트는 한 번 누르면 최대 세 발을 발사하고, 글라스핀은 한 번 누를 때 한 발씩 발사합니다.

## 여러 크롬북에서 대전

웹 게임의 **친구와 대전**에서 방장이 1v1, 2v2 또는 3v3을 선택해 방을 만듭니다. 친구는 **코드로 참가**에 6자리 코드를 입력하거나 초대 링크를 엽니다. 방장은 경기 동안 탭을 열어 두세요.

학교 네트워크에서 온라인 연결이 제한되면 행사장 LAN 서버를 사용할 수 있습니다.

1. 진행자 PC와 참가할 크롬북을 같은 네트워크에 연결합니다.
2. 웹 게임에서 **친구와 대전 → 연결이 안 되나요? → 서버 묶음**을 눌러 ZIP을 풀거나 이 저장소를 내려받습니다.
3. 진행자 PC에 Node.js 18 이상을 설치합니다. Windows에서는 `start-windows.cmd`를 실행하고, macOS·Linux에서는 저장소 폴더에서 `node server.mjs`를 실행합니다.
4. 참가자 모두 서버 창에 표시된 **LAN 주소**를 Chrome에서 엽니다. 방장이 1v1, 2v2 또는 3v3 방을 만들면 다른 참가자는 4자리 코드로 입장합니다.

기본 포트는 8787입니다. 경기 중에는 서버 창을 열어 두세요. [축제 진행 안내](PLAY-KO.txt)에 방 설정, 빈자리 봇, 학교 Wi-Fi 접속 문제 해결 방법이 있습니다.

## 수정하고 배포하기

- [맵](dist/arena-map.js)에서 지형과 시작 위치, [밸런스](dist/balance.js)에서 체력과 무기 수치, [경기 규칙](dist/sim.js)에서 판정과 라운드, [봇 전술](dist/tactics.js)에서 봇의 행동을 조정할 수 있습니다.
- `node server.mjs` 실행 후 [로컬 게임](http://localhost:8787/)에서 확인하세요. 게임에 필요한 라이브러리는 저장소에 포함되어 있습니다.
- 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정하세요. [배포 워크플로](.github/workflows/pages.yml)가 `main`에 변경 사항을 푸시할 때 게임과 최신 LAN 서버 ZIP을 함께 배포합니다. 공개 사이트에서는 방장의 브라우저가 경기를 진행하고, 행사장 LAN에서는 진행자 PC의 Node 서버가 경기를 진행합니다.

두 팀의 세관 대원은 DOCKLINE용으로 Tripo에서 생성했습니다. [캐릭터 변환 스크립트](art-source/customs/)에서 원본에 이동·조준 동작을 연결하고 WebGL 모델과 경량판을 만듭니다. 1인칭 장갑은 현장 대응팀 원본에서 추출해 손가락 관절을 연결했습니다. [Toon Shooter 원본](art-source/toon-shooter/README.txt)에는 캐릭터 동작과 일부 총기의 출처가 있습니다. [외부 코드·모델·녹음 이용 조건](dist/assets/)과 [글꼴 라이선스](dist/fonts/OFL.txt)를 포함합니다.
