# DOCKLINE · 서밋 아레나

크롬북과 마우스로 즐기는 학교 축제용 2v2·3v3 FPS. 40초 라운드에서 상대 팀을 전멸시키거나 연장전에 중앙 발판을 점령하세요. 먼저 세 라운드를 이기는 팀이 승리합니다.

## 바로 플레이

[브라우저에서 도크라인 플레이](https://juhyeonmoon10.github.io/dockline-summit/) · [축제용 LAN 서버 ZIP 다운로드](https://juhyeonmoon10.github.io/dockline-summit/dockline-lan.zip)

무기를 선택하고 **더미 사격장**을 누르세요. 거리와 높이가 다른 더미 4개를 시간 제한 없이 쏠 수 있습니다. 더미는 쓰러지고 1.5초 뒤에 다시 서며, 화면 위에 명중 수·처치 수·명중률이 표시됩니다.

| 조작 | 키 |
| --- | --- |
| 이동 · 시점 | WASD · 마우스 |
| 발사 · 조준 | 좌클릭 · 우클릭 |
| 점프 · 슬라이딩 | Space · 이동 중 C |
| 재장전 · 무기 교체 | R · 1(주무기) / 2(권총) |
| 사격장에서 주무기 변경 | Q |
| 메뉴 · 마우스 감도 | Esc |

Esc 메뉴 또는 로비 오른쪽 위 설정에서 마우스 감도를 0.10–3.00배로 조절할 수 있습니다. 슬라이더나 숫자를 바꾸면 바로 적용되어 이 브라우저에 저장됩니다. 기본값은 1.00배입니다.

## 체력과 무기

일반 대전의 플레이어와 사격장 더미는 모두 150 HP입니다. 아래는 2026-11-06에 확인한 RIVALS 커뮤니티 무기 기록을 적용한 근거리 수치입니다. 탄창·예비탄, 재장전과 장착 시간, 거리 감쇠도 공통 데이터에서 계산합니다. [무기 수치](https://bloxguidesgg.com/games/rivals/wiki/weapons) · [장착 시간](https://bloxguidesgg.com/games/rivals/tier-list)

| 무기 | 몸통 / 머리 | 발사 간격 | 탄창 / 예비탄 | 150 HP 몸통 처치 |
| --- | --- | --- | --- | --- |
| 돌격소총 | 12 / 15 | 0.10초 | 20 / 100 | 13발 |
| 산탄총 | 8×10 / 12×10 | 0.70초 | 7 / 35 | 2발, 산탄 전부 명중 시 |
| 저격소총 | 50 / 150 | 1.50초 | 4 / 12 | 3발 |
| 권총 | 12 / 15 | 0.13초 | 13 / 91 | 13발 |

저격 헤드샷은 150 피해입니다. 원작의 스터드 단위를 이 맵의 미터로 바꿔, 돌격소총은 14–56m, 권총은 14–35m, 산탄총은 2.8–14m에서 피해가 감소합니다. [감쇠 기록](https://gamesdatahub.com/wikis/rivals/weapons/) · [Roblox 길이 단위](https://create.roblox.com/docs/physics/units)

산탄총은 한 발씩 장전하며, 정확한 원작 삽입 시간 자료가 없어 한 발당 0.77초로 조정했습니다. 돌격소총과 권총의 조준 분산은 비조준 분산의 24%로 적용했습니다. 이 웹버전은 네 총 모두 좌클릭을 누르면 각 무기의 발사 간격으로 발사합니다. 사격장의 예비탄은 무제한이고, 팀전의 탄창과 예비탄은 새 라운드마다 보충됩니다.

## 여러 크롬북에서 대전

1. 진행자 PC와 참가할 크롬북을 같은 네트워크에 연결합니다.
2. 웹 게임에서 **친구와 대전 → 대전 서버 묶음 다운로드**를 눌러 ZIP을 풀거나 이 저장소를 내려받습니다.
3. 진행자 PC에 Node.js 18 이상을 설치합니다. Windows에서는 `start-windows.cmd`를 실행하고, macOS·Linux에서는 저장소 폴더에서 `node server.mjs`를 실행합니다.
4. 참가자 모두 서버 창에 표시된 **LAN 주소**를 Chrome에서 엽니다. 방장이 2v2 또는 3v3 방을 만들면 다른 참가자는 4자리 코드로 입장합니다.

기본 포트는 8787입니다. 경기 중에는 서버 창을 열어 두세요. [축제 진행 안내](PLAY-KO.txt)에 방 설정, 빈자리 봇, 학교 Wi-Fi 접속 문제 해결 방법이 있습니다.

## 수정하고 배포하기

- [맵](dist/arena-map.js)에서 지형과 시작 위치, [밸런스](dist/balance.js)에서 체력과 무기 수치, [경기 규칙](dist/sim.js)에서 판정과 라운드, [봇 전술](dist/tactics.js)에서 봇의 행동을 조정할 수 있습니다.
- `node server.mjs` 실행 후 [로컬 게임](http://localhost:8787/)에서 확인하세요. 게임에 필요한 라이브러리는 저장소에 포함되어 있습니다.
- 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정하세요. [배포 워크플로](.github/workflows/pages.yml)가 `main`에 변경 사항을 푸시할 때 게임과 최신 LAN 서버 ZIP을 함께 배포합니다. GitHub Pages에서는 사격장이 브라우저에서 실행되고, 여러 기기의 방과 점수는 진행자 PC의 Node 서버가 관리합니다.

총기 원본 OBJ와 변환 방법은 [무기 원본](art-source/blasters/README.txt)에 있습니다. [외부 코드·모델·녹음 이용 조건](dist/assets/)과 [글꼴 라이선스](dist/fonts/OFL.txt)를 포함합니다.
