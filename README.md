# DOCKLINE · 서밋 아레나

크롬북과 마우스로 즐기는 학교 축제용 2v2·3v3 FPS. 40초 라운드에서 상대 팀을 전멸시키거나 연장전에 중앙 발판을 점령하세요. 먼저 세 라운드를 이기는 팀이 승리합니다.

## 바로 플레이

저장소 오른쪽 **Deployments → github-pages → View deployment**에서 게임을 엽니다. 돌격소총·산탄총·저격소총 중 하나를 선택한 뒤 **봇 대전 시작**을 누르세요. **사격 연습**에서는 표적에 먼저 쏴 볼 수 있습니다.

| 조작 | 키 |
| --- | --- |
| 이동 · 시점 | WASD · 마우스 |
| 발사 · 조준 | 좌클릭 · 우클릭 |
| 점프 · 슬라이딩 | Space · 이동 중 Shift |
| 재장전 · 무기 교체 | R · 1(주무기) / 2(권총) |

## 여러 크롬북에서 대전

1. 진행자 PC와 참가할 크롬북을 같은 네트워크에 연결합니다.
2. 웹 게임에서 **친구와 대전 → 대전 서버 묶음 다운로드**를 눌러 ZIP을 풀거나 이 저장소를 내려받습니다.
3. 진행자 PC에 Node.js 18 이상을 설치합니다. Windows에서는 `start-windows.cmd`를 실행하고, macOS·Linux에서는 저장소 폴더에서 `node server.mjs`를 실행합니다.
4. 참가자 모두 서버 창에 표시된 **LAN 주소**를 Chrome에서 엽니다. 방장이 2v2 또는 3v3 방을 만들면 다른 참가자는 4자리 코드로 입장합니다.

기본 포트는 8787입니다. 경기 중에는 서버 창을 열어 두세요. [축제 진행 안내](PLAY-KO.txt)에 방 설정, 빈자리 봇, 학교 Wi-Fi 접속 문제 해결 방법이 있습니다.

## 수정하고 배포하기

- [맵](dist/arena-map.js)에서 지형과 시작 위치, [경기 규칙](dist/sim.js)에서 무기 성능과 라운드, [봇 전술](dist/tactics.js)에서 봇의 행동을 조정할 수 있습니다.
- `node server.mjs` 실행 후 [로컬 게임](http://localhost:8787/)에서 확인하세요. 게임에 필요한 라이브러리는 저장소에 포함되어 있습니다.
- 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 설정하세요. [배포 워크플로](.github/workflows/pages.yml)가 `main`에 변경 사항을 푸시할 때 게임과 최신 LAN 서버 ZIP을 함께 배포합니다. GitHub Pages에서는 브라우저가 봇 경기를 실행하고, 여러 기기의 방과 점수는 진행자 PC의 Node 서버가 관리합니다.

총기 원본 OBJ와 변환 방법은 [무기 원본](art-source/blasters/README.txt)에 있습니다. [외부 코드·모델·녹음 이용 조건](dist/assets/)과 [글꼴 라이선스](dist/fonts/OFL.txt)를 포함합니다.
