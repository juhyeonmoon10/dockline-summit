도크라인 | 크롬북 팀전 시작 안내

설치 없이 온라인으로 참가하기
  1. 모두 https://juhyeonmoon10.github.io/dockline-summit/ 에 접속하세요.
  2. 방장은 2 VS 2 또는 3 VS 3을 선택하고 '친구와 대전' → 이름 입력 → '방 만들기'를 누릅니다.
  3. '코드 복사'로 6자리 방 코드를 친구에게 보내세요. 친구는 같은 사이트에서 코드를 입력하고 '참가하기'를 누릅니다.
     '초대 링크 복사'로 보낸 링크는 코드가 자동으로 채워집니다.
  4. 참가자가 '준비 완료'를 누르면 방장이 경기를 시작합니다. 빈자리는 봇으로 채울 수 있습니다.
  방장의 브라우저가 경기 판정을 진행합니다. 방장이 나가거나 탭을 닫으면 방이 종료됩니다.
  인터넷 연결과 WebRTC를 허용하는 네트워크가 필요합니다. 공용 PeerJS 연결 서비스가 중단되거나
  학교·게스트 Wi-Fi가 기기 간 통신을 차단하는 경우 연결되지 않을 수 있습니다. PeerJS의 기본 연결·중계 설정을 사용합니다.
  아래 행사장 서버 방식은 인터넷 연결 없이 같은 네트워크에서도 사용할 수 있습니다.

준비물
  진행용 컴퓨터 한 대와 크롬북 4대(2대2) 또는 6대(3대3)를 같은 네트워크에 연결하세요.
  진행용 컴퓨터의 브라우저도 선수 한 자리로 사용할 수 있습니다. 자리가 남으면 봇이 채울 수 있습니다.
  크롬북에서는 Chrome을 열고 외장 마우스와 키보드로 플레이합니다.
  진행용 컴퓨터에는 Node.js 18 이상이 필요합니다. 필요한 경우 https://nodejs.org/ 에서 LTS를 설치하세요.

서버를 켜고 참가하기
  1. 진행용 컴퓨터에서 서버 ZIP을 폴더에 전부 풉니다. dist, package.json, server.mjs는 함께 둡니다.
  2. Windows에서는 start-windows.cmd를 더블클릭하세요. macOS·Linux에서는 이 폴더에서 node server.mjs를 실행하세요.
  3. 진행자는 http://localhost:8787/ 를 엽니다. 크롬북에서는 서버 창에 나온 LAN 주소(예: http://192.168.1.12:8787/)를 엽니다.
     서버 창을 경기 동안 열어 두세요. 인터넷 연결 없이도 진행용 컴퓨터와 크롬북이 서로 연결된 네트워크에서 플레이할 수 있습니다.
  4. 한 명이 '2 VS 2' 또는 '3 VS 3'을 선택한 뒤 '친구와 대전' → 이름 입력 → '방 만들기'를 누릅니다.
  5. 나머지는 같은 주소에서 '친구와 대전'을 누르고 이름과 방 코드 4자리를 입력해 참가합니다.
     참가자가 '준비 완료'를 누르면 방장이 '경기 시작' 또는 '빈자리 봇으로 시작'을 누를 수 있습니다.
  6. 시작되면 경기 화면을 클릭해 마우스 시점을 켜세요. Esc로 마우스를 풀거나 메뉴를 엽니다.
     끝낼 때 진행용 컴퓨터의 서버 창에서 Ctrl+C를 누릅니다.

한 경기
  기본 체력은 150이며, 새 라운드마다 각 무기의 탄창과 예비탄이 보충됩니다.
  준비 시간 15초 동안 움직여 보고 무기를 고르세요. 한 라운드는 40초, 각자 목숨은 하나입니다.
  상대 전원을 처치하면 라운드 승리입니다. 연장 10초에는 중앙 거점을 상대 없이 3초 동안 점령해도 이깁니다.
  3승을 먼저 얻거나 5라운드가 끝나면 최종 점수가 표시됩니다.

조작
  WASD 이동 / 마우스 이동으로 시점 조절 / 좌클릭 발사 / 우클릭 조준
  Space 점프 / 이동 중 C 슬라이딩 / R 재장전 / 1 주무기 / 2 권총 / 3 칼
  칼을 든 상태에서 좌클릭하면 가까운 대상을 공격합니다.
  Q 주무기 변경(사격장·팀전 준비 시간·라운드 사이) / Tab 관전 대상 변경 / Esc 메뉴
  화면이 끊기면 설정에서 그래픽을 '저사양'으로 바꿔 보세요.
  Esc 메뉴 또는 로비 설정에서 마우스 감도를 0.10–3.00배로 조절할 수 있습니다. 슬라이더와 숫자 입력을 지원하고 값은 이 브라우저에 저장됩니다. '기본값'은 1.00배입니다.

주소에 접속할 수 없을 때
  먼저 진행용 컴퓨터에서 localhost 주소가 열리는지 보고, 크롬북에는 서버 창의 실제 LAN 주소를 입력했는지 확인하세요.
  Windows 방화벽에서 Node.js 허용 여부를 묻는다면 학교에서 허용한 개인 네트워크만 선택하세요.
  공용·게스트 Wi-Fi는 같은 Wi-Fi에 연결된 기기 사이 통신을 차단할 수 있습니다.
  이 경우 학교 담당자에게 진행용 컴퓨터의 TCP 8787 포트에 접근할 수 있는 행사 네트워크를 요청하세요.
  서버 창에 주소가 여러 개 표시되면 진행용 컴퓨터가 행사 Wi-Fi에 연결할 때 받은 IPv4 주소를 선택하세요.

  배포된 웹페이지는 위의 온라인 6자리 코드 방식으로 참가할 수 있습니다.
  행사장 서버의 4자리 방 코드는 해당 서버 주소에서만 사용할 수 있습니다.
  별도 연습용 HTML에서는 더미 사격장을 이용하거나 '온라인 게임 열기'로 사이트에 접속하세요.

서밋 아레나 및 소스 수정
  서밋은 산업 시설 옥상의 아레나입니다. 팀 색상의 컨테이너, 금속 화물 케이스, 공장·급수탑·크레인 배경으로 경로를 구별합니다.
  중앙 경사로·아래 통로·양쪽 고지대와 엄폐물의 충돌 크기는 그래픽 모드에 관계없이 같습니다.
  환경 모델은 Kenney CC0 에셋입니다. art-source/environment에 원본 OBJ·팔레트·라이선스와 변환 도구가 있습니다.
  dist/arena-art.js는 WebGL 맵 연출을, dist/arena-props.js는 환경 에셋을, dist/lite.js는 경량 모드 연출을 담당합니다.
  사격장에는 거리와 높이가 다른 고정 더미 4개가 있습니다. 더미는 처치 후 1.5초 뒤에 다시 서고 명중 수·처치 수·명중률이 화면 위에 표시됩니다. Esc 메뉴에서 로비로 나갈 수 있습니다.
  중앙 지붕의 점령 지점은 양쪽 경사로로 올라갑니다. 지붕 아래 통로는 옆으로 빠질 때 쓸 수 있습니다.
  dist/arena-map.js가 맵의 치수, 엄폐물, 경사로, 점령 지점, 시작 위치를 정합니다. 경기 판정과 그래픽이 이 파일을 함께 사용합니다.
  dist/balance.js에서 체력과 무기 수치를, dist/tactics.js에서 봇 전술을, dist/sim.js에서 판정과 경기 규칙을 수정할 수 있습니다.
  art-source/toon-shooter에 현재 총기의 OBJ·MTL, 병사 glTF와 변환 도구가 있습니다. Quaternius Toon Shooter Game Kit(CC0)를 수정한 모델입니다.
  이전 Kenney 원본도 art-source/blasters에 보관했습니다. 자료별 이용 조건은 art-source의 README와 dist/assets/*LICENSE.txt 및 *CREDITS.txt에 들어 있습니다.
  게임 규칙이나 맵을 편집했다면 실행 중인 서버를 재시작하고 모든 참가자가 브라우저를 새로고침하세요.
